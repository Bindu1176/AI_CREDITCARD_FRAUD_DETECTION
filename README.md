## 📌 Overview

**AI Credit Card Fraud Detection** uses Machine Learning to analyze transaction data and identify suspicious or potentially fraudulent transactions.

The project focuses on applying data preprocessing, feature analysis, and machine learning techniques to build an automated fraud detection system.

## 🎯 Key Features

* 🔍 Detect potentially fraudulent transactions
* 📊 Analyze transaction patterns
* 🤖 Machine Learning-based prediction
* ⚡ Automated fraud classification
* 🌐 User-friendly prediction interface

## 🛠️ Tech Stack

* **Python**
* **Pandas & NumPy**
* **Scikit-learn**
* **Flask**
* **HTML/CSS**
* **Machine Learning**

## 🔄 Workflow

```text
Transaction Data
       ↓
Data Preprocessing
       ↓
Feature Analysis
       ↓
ML Model
       ↓
Fraud / Legitimate
       ↓
Prediction Interface
```

## 🚀 Objective

To demonstrate how **Artificial Intelligence and Machine Learning can be used to detect fraudulent financial transactions and support safer digital payments.**
